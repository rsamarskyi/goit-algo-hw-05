Порівняння алгоритмів пошуку підрядка
Мета роботи
Порівняти швидкість алгоритмів Боєра–Мура, Кнута–Морріса–Пратта (КМП) та Рабіна–Карпа на основі двох текстових файлів.
Проведення вимірювань
Для кожного тексту використано два підрядки:
- наявний — фрагмент із середини тексту;
- відсутній — Цього підрядка немає у статті!.
Час виміряно за допомогою timeit: кожен пошук виконано 100 разів. У таблицях наведено середній час одного виклику в секундах. Читання файлів не входить у вимірювання, а підготовка допоміжних таблиць і хешів входить. Правильність результатів перевірено порівнянням із методом str.find().

Для загального порівняння підсумовано середній час одного виклику в кожному з чотирьох сценаріїв. Усі сценарії мають однакову вагу.

Висновки
Алгоритм Боєра–Мура виявився найшвидшим для кожного тексту окремо та в цілому. Він може пропускати кілька позицій тексту при невідповідності символів, що допомагає скоротити кількість порівнянь. У реалізації використано правило поганого символу.

КМП посів друге місце в усіх вимірюваннях. Він використовує префіксну таблицю, щоб уникати повторних порівнянь. Рабін–Карп був найповільнішим у цьому експерименті: обчислення ковзного хешу в реалізації на Python додає витрати часу.

Пошук відсутнього підрядка потребував більше часу в усіх випадках, оскільки алгоритми перевіряли текст до кінця. Пошук наявного підрядка завершувався при першому входженні.

Ці висновки стосуються обраних текстів, підрядків і реалізацій. Для інших даних або іншого середовища результати можуть відрізнятися.
